# 项目管理工作台 · 宣传文案

## 标题

我把项目资料、沟通记录和 Agent，放进了同一个工作台

## 可直接发布的介绍

做项目时，最费劲的往往不是缺一个任务列表，而是信息散在太多地方：文档里有方案，沟通里有变更，日程里有约定，想知道项目现在怎么样，还得重新翻一遍。

我最近把自己一直在用的工作台整理成了一个公开展示版本，叫「项目管理工作台」。

首页集中看项目阶段、经营数据和本周安排。深入到项目，可以核对当前判断、卡点、材料与历史；旁边常驻一个 Agent 入口，用来找文件、问进展和理解上下文。资料同步和项目分析放在后台，但来源、失败和待核验状态仍然能看到。

它目前偏销售项目协作，仍在迭代。公开版本附虚构数据的离线演示；连接 CRM、邮箱、日历、会议记录和本机 Agent 需要自行配置。我没有把真实客户材料、账号或公司内部配置放进去。

项目主页：https://github.com/pandongxu0873-coder/project-workbench

这次是公开代码供展示和交流，暂未授予额外使用或商用许可。欢迎看界面、提工作流程建议，也欢迎告诉我：你管理项目时，最难找回的是哪一类信息？

## 一句话介绍

带 Agent 的项目管理工作台：把资料、沟通、项目判断与日程放在同一条可追溯的推进路径上。
